# vamsin07.github.io

Personal site of Shivam Singh. A plain static site: `index.html` plus photos in `img/`. No build step.

- Edit text: open `index.html` in any editor and change the words.
- Add a photo: put a resized JPG (about 1200px on the long side) in `img/`, then copy one of the `<figure class="piece">` blocks in Room I and change the file name, alt text and placard.
- Add a blog post: copy the `<li class="post">` entry in the Reading room list and the `<article class="post-view">` block, give the new article its own id, and add that id to the small router at the bottom of the page.
